# 🎮 Escenario 3D Interactivo con Three.js (FPS)

## 📌 Descripción
Este proyecto consiste en el desarrollo de un escenario 3D interactivo utilizando la librería Three.js. Se implementa un sistema de control tipo FPS (First Person Shooter), permitiendo al usuario desplazarse dentro del entorno virtual mediante el uso del teclado y el mouse.

El objetivo principal es simular la interacción en un ambiente 3D, integrando modelos descargados y aplicando controles similares a los de un videojuego.

---

## 🎯 Objetivo
Desarrollar una aplicación web que permita implementar un ambiente virtual 3D con controles FPS, integrando modelos 3D y utilizando tecnologías basadas en WebGL.

---

## 🛠️ Tecnologías utilizadas
- JavaScript
- Three.js
- WebGL
- HTML5
- CSS3

---

## 🎮 Funcionalidades
- Movimiento en primera persona (FPS)
- Control con teclado (W, A, S, D)
- Control de cámara con mouse
- Integración de modelos 3D externos
- Renderizado en tiempo real
